# AirGuard

## Segue 3.0 — Team Tech Wizzards

AirGuard is a Smart Inhaler project designed to monitor environmental conditions and provide proactive health-risk alerts.

### Team Development Rule

> **Do NOT commit directly to the `main` branch.**

All team members must follow this workflow:

1. Create your own feature branch.
2. Make and test your changes on that branch.
3. Commit your changes.
4. Push your branch to GitHub.
5. Create a Pull Request to `main`.
6. Get the changes reviewed before merging.

### Branch Workflow

```text
main
 │
 ├── feature/your-name
 │       ↓
 │    Develop
 │       ↓
 │    Test
 │       ↓
 │    Commit
 │       ↓
 │    Push
 │       ↓
 └── Pull Request → main
